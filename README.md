# 星冠云国 · 艾尔芙海姆 (Voxel Dream Kingdom)

基于 **Three.js + TypeScript + Vite** 构建的方块像素风（MagicaVoxel / 天空之城童话风）3D 梦幻浮空王国。

🌐 **在线体验地址**：[https://ironadd.github.io/voxel-dream-kingdom/](https://ironadd.github.io/voxel-dream-kingdom/)

## ✨ 核心特性
- **手绘像素艺术纹理 + 逐顶点 AO**：程序化生成 50+ 款 16×16 像素纹理，配合分块隐藏面剔除与薰衣草紫调环境光遮蔽（AO）及 `UnrealBloomPass` 柔光辉光后处理。
- **立体云端奇观建筑群**：皇家星冠大城堡、风车花语童话镇、星泉喷泉广场、千年绯樱神木、七彩彩虹拱桥、紫晶星象台浮岛、星辉灯塔岛与底部拉普达飞行蓝水晶核。
- **四时梦幻天象**：支持 `🌸 晨曦樱华`、`☀️ 晴空童话`、`🌇 黄昏金辉`、`🌌 星夜幻境` 一键切换与自动流转。
- **多元互动**：支持 `🦅 自由俯瞰`、`🎬 电影环游`、`🚶 第三人称漫步/御风飞行`，可绽放像素烟花、放飞祈愿天灯、自由建造方块及开启 Web Audio 八音盒。

## 🚀 本地运行与发布
- 双击 `启动游戏.bat`（或执行 `npm install && npm run dev`）启动本地开发预览。
- 双击 `发布线上版.bat` 自动构建并更新至 GitHub Pages。
